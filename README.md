# 記憶のバー

グラスに映る、あの日の景色。

夜のバーでお客さんの話を聞き、今の気持ちに合う一杯を作る全3話のブラウザゲームです。
気持ちに合う一杯を出すと、グラスの中に忘れていた記憶がよみがえります。

- [現行版](https://jirisuke0121.github.io/kioku-bar/) は、以前の `?proto` と同じ3話を収録しています。
- [旧本編のアーカイブ](https://jirisuke0121.github.io/kioku-bar/?archive) はタイトル画面からも開けます。以前と同じブラウザでは、保存済みの進行や図鑑を引き継げます。

## 遊び方

1. 「開店する」をタップ
2. お客さんの話から、今の気持ちを読み取る
3. ベース(気持ちの色)・香り(胸の内の動き)・飾り(どんな日か)を一つずつ選ぶ
4. 「提供する」で、お客さんの反応と、お話のどこが手がかりだったかが分かる

スマホの縦画面で遊べます。グラスはドラッグで傾けられます。

## 動かし方

ビルド不要の静的サイトです。`index.html` を開くだけで動きます
(three.js とフォントは CDN から読み込むため、通信が必要です)。

ローカルで試す場合:

```
python3 -m http.server 8000
```

その後 `http://localhost:8000/` を開いてください。

## 使っているもの

- [three.js](https://threejs.org/)
- Google Fonts(Shippori Mincho / Zen Kaku Gothic New)
- 景色と人物の絵は、画像生成AIで作成した素材を使っています
- 効果音と音楽は Web Audio でその場で合成しています
